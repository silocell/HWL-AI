# HWLAI

The Homework Launchpad's own search AI, at **hwlai.civilinitiatives.org**. Ask a question; HWLAI searches the web (the Launchpad's own SearXNG, SafeSearch strict), reads the top pages and answers with numbered sources. Free for signed-in pupils. Follow-ups continue in Launchpad AI.
